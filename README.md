# HydroSpatial – Real-Time Water Intelligence Platform

A real-time hydrological intelligence system built using **React**, **Django**, and **Gemini API**, providing analytics and insights on water levels across **25+ Indian states**.

---

## Live Deployment:
🔗 **Production URL:**

---

## ☁️ AWS Deployment Architecture:

### **Deployed Using:**
- **AWS CodePipeline** – CI/CD automation  
- **AWS CodeBuild** – Build & Test  
- **AWS CodeArtifact** – Dependency & artifact management  
- **AWS S3** – Static hosting for React  
- **AWS EC2** – Django backend  
- **Amazon CloudWatch** – Logs & monitoring
